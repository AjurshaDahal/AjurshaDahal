## `03` — Selected projects

A collection of academic and personal projects where I've explored different areas of software development and intelligent systems.

### 01. Retail Object Removal Detection

<code>Python</code> <code>PyTorch</code> <code>OpenCV</code> <code>YOLO</code> <code>MiDaS</code>

Developed an AI-driven approach to detect removed objects from retail shelves using 3D spatial changes rather than relying on individual product classification models.

- Generated depth maps and 3D shelf representations.
- Applied volumetric change detection between shelf observations.
- Used object detection and spatial proximity analysis to distinguish potential removal from legitimate activity.

### 02. Online Voting System

<code>React</code> <code>Flask</code> <code>MySQL</code> <code>OpenCV</code> <code>dlib</code>

A full-stack voting platform designed to manage elections, candidates, voters, and automated results.

- Implemented voter authentication with face recognition.
- Developed election and candidate management workflows.
- Worked on unit, integration, system, and API testing.

### 03. Real-Time Face Recognition Attendance System

<code>Python</code> <code>OpenCV</code> <code>CVZone</code> <code>Firebase</code>

A real-time attendance system that uses face recognition to identify registered individuals and record attendance.

- Implemented face detection and recognition.
- Integrated persistent attendance storage with Firebase.
- Tested recognition under different lighting and camera conditions.

### 04. Degah — AR Heritage Tour Guide

<code>Unity</code> <code>C#</code> <code>Vuforia</code> <code>JSON</code>

An offline augmented reality tour guide designed to make heritage exploration more interactive.

- Integrated image-target recognition and GPS-based presence validation.
- Designed a three-phase narration experience.
- Added interactive clues and badge-based gamification.

### 05. Team Finder — Gaming Recruitment Platform

<code>Python</code> <code>Django</code> <code>HTML</code> <code>CSS</code>

A platform for gamers to create profiles, showcase skills and ranks, and find teammates.

- Developed authentication and user profiles.
- Implemented team requirements and skill-matching workflows.

### 06. House Price Prediction

<code>Python</code> <code>Machine Learning</code> <code>Data Analysis</code>

An exploration of machine learning for predicting house prices using the California Housing dataset.

- Worked with a publicly available housing dataset.
- Explored the machine learning prediction workflow.
